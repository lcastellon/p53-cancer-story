# P53 Cancer Story

Voy a hacer una presentación interactiva de diapositivas del libro "p53: The Gene That Cracked the Cancer Code" de Sue Armstrong para divulgación general de unos 50-60 minutos. Haz la presentación interactiva completa basada en el documento adjunto (26 diapositivas divididas en 5 actos narrativos), con controles de navegación (teclado flechas / clics / barra de progreso), modo pantalla completa, vista para orador con notas y tiempos, y un diseño visual moderno, científico y accesible.

This project was built with [Lovable](https://lovable.dev).
